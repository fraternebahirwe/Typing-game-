## ✨ Features & Gameplay

- **Dual Practice Modes:** Switch seamlessly between single **Words (`Mots`)** and full **Phrases (`Phrases`)**.
- **Real-time Live Stats:** Tracks correct words (`Bons`), total attempts (`Total`), and typing accuracy (`Précision %`).
- **Dynamic Progress Bar:** Visual feedback indicator (`#progressBar`) showing game completion state.
- **Score Sharing:** Built-in share feature (`Partager mon score`) to challenge friends and export performance metrics.
- **Accessible UI:** Engineered with screen-reader friendly utility classes (`.sr-only`), `aria-live` polite regions, dynamic `aria-pressed` states, and full keyboard navigation support.

---

## 🛠️ Built With

- **HTML5:** Modern semantic markup with comprehensive accessibility (`aria-*`) tags.
- **CSS3:** Custom stylesheet with modern dark mode styling (`style.css`).
- **JavaScript (ES6+):** Modular game logic, DOM manipulation, input validation, and statistical tracking (`script.js`).
